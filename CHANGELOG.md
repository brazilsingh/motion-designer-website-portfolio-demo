# Changelog

## 1.0.0 (2026-11-17)

First release as a reusable template.

### Added

- **Demo personas:** open the site with `?demo=3d-artist`, `?demo=yt-editor` or `?demo=brand-motion` to see the template with different content and accent colours.
- **AI setup:** `AGENTS.md`, a `/clone` command for Claude Code, and the `motion-portfolio` Claude skill, so any AI agent can personalise the site while keeping the design.
- **Prompt pack:** `PROMPTS.md` with copy-paste prompts.
- **Search and sharing:** title and description, canonical link, Open Graph and X cards, JSON-LD structured data, `sitemap.xml`, a share image, a favicon, and real text in the HTML before JavaScript runs.
- **Project files:** MIT licence, contributing guide, code of conduct, security policy, issue forms, a pull request template, and a **Check** workflow.

### Site features

- 3D hero with a ring of film frames built from your video thumbnails.
- Draggable lanyard ID card.
- Long-form and Shorts rails that load YouTube thumbnails from a link.
- Editing-timeline process section.
- Hover reveal photo.
- Contact rows with copy email and WhatsApp.
- 3D "let's collab" button (Venom Button by exteestudio).
