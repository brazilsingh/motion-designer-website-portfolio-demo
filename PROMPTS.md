# Prompt pack

Copy-paste prompts for any AI coding agent (Claude Code, Cursor, GitHub Copilot, Codex and others), used inside this repo. Replace the text in `[brackets]`.

## Make it yours

**Personalise everything**
```
Follow the "Clone flow" in AGENTS.md. Ask me for all my details first,
wait for my answers, then update the content. Keep the design exactly as it is.
```

**Fill it from my CV or LinkedIn**
```
Here is my CV / LinkedIn text: [paste]. Use it to fill the CONTENT object in
script.js: name, roles, tagline, about, skills and strengths. Ask me for anything
that's missing. Then update the SEO block and the data-c text in index.html to match.
```

**Add my videos**
```
Add these videos to my portfolio, newest first. Long-form: [links].
Shorts: [links]. Fetch each video's real title from YouTube and use
"Client · [name]" as the meta line. Update the workExample list in the JSON-LD too.
```

## Change the look

**Change the accent colour**
```
Change the accent colour to [#hex] everywhere it's used, including the
hard-coded reds in style.css. Check that text on the accent colour still has
a contrast ratio of at least 4.5:1.
```

**Try a demo style first**
```
Open index.html?demo=3d-artist, ?demo=yt-editor and ?demo=brand-motion.
Tell me which one is closest to my work: [describe your work].
```

**Swap my photos**
```
I've added [photo-1] and [photo-2]. Make them 1000×1000 WebP with a transparent
background, the same framing for both, and put them in assets/ as me-front.webp
(normal) and me-mask.webp (the reveal version).
```

## Write the words

**Write my bio**
```
Write a 2 to 3 sentence about text for a [video editor / motion designer] who
[what you do] for [who you work with]. Plain words, first person, no buzzwords.
Give me 3 options.
```

**Write my tagline**
```
Give me 5 one-line taglines (under 12 words) for a [your role] whose work is
known for [your strength]. Plain and confident.
```

## Get found

**Check my SEO**
```
Check the SEO block in index.html against the CONTENT in script.js. Make the
title under 60 characters, the description 140 to 160 characters, and fix
anything that doesn't match. Validate the JSON-LD.
```

**Make a share image**
```
Take a 1200×630 screenshot of my live hero and save it as assets/og-image.jpg.
```

## Publish

**Put it online for free**
```
Walk me through publishing this repo on GitHub Pages, step by step, and give
me my final link.
```

## Translate

**Make it bilingual**
```
Translate all visible text in CONTENT, and the SEO block, into [language].
Keep names, tool names and video titles in their original language.
```
