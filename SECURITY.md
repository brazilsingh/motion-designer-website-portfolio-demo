# Security policy

This is a static website template. It has no server, database or login, so its security risks are small. They can still happen, for example a script injection through content or an unsafe third-party embed.

## Supported versions

Only the latest release and the `main` branch get fixes.

## Report a problem

Please don't open a public issue for a security problem. Report it privately instead:

1. Go to the [Security tab](https://github.com/brazilsingh/motion-designer-website-portfolio-demo/security) of this repo.
2. Click **Report a vulnerability**.

Include what you found, how to reproduce it, and which file is affected. You should get a reply within 7 days. Once it's fixed, you'll be credited in the changelog unless you'd rather not be.
